## Overview

CardioFusion is a full-stack multimodal AI system that fuses **1000-point ECG waveforms** with **11 Electronic Health Record features** to stratify Heart Failure risk. Clinical classifications follow **ACC/AHA 2022 HF Guidelines** and **NYHA Functional Classes**.

### Architecture

```
┌─────────────────────────────────────────────────────────────────┐
│                        React Dashboard (port 3000)              │
│     ECG Visualisation · EHR Form · Risk Gauge · SHAP Chart     │
└────────────────────────────┬────────────────────────────────────┘
                             │ POST /analyse
┌────────────────────────────▼────────────────────────────────────┐
│              Node.js Gateway (Express, port 3001)               │
│         Template-based Clinical Summary · Input Validation      │
└────────────────────────────┬────────────────────────────────────┘
                             │ POST /predict
┌────────────────────────────▼────────────────────────────────────┐
│            Python AI Service (FastAPI + Gunicorn, port 8000)    │
│  Dual-Branch CNN+MLP Fusion · Rules Engine · SHAP (async)       │
└─────────────────────────────────────────────────────────────────┘
```

### ML Architecture

```
ECG Input (1000×1)          EHR Input (11 features)
        │                           │
   Conv1D ×3                    Dense-64
   BatchNorm                    BatchNorm
   MaxPool                      Dropout-0.3
   Flatten                      Dense-32
   Dense-32                     Dense-32
        │                           │
        └──── Gated Attention ───────┘
                    │
               Dense-1 (Sigmoid)
               HF Risk Score
```

## Quick Start

### Prerequisites
- Docker ≥ 24.0 and Docker Compose v2
- Python 3.10 (for training only)

### 1 – Train the model (one-time)

```bash
cd ml-training
pip install tensorflow scikit-learn numpy pandas

# With PTB-XL dataset (recommended):
python train.py --ptbxl-root /path/to/ptb-xl

# Without PTB-XL (uses clinically-plausible synthetic data):
python train.py

# Copy artefacts to AI service
cp artefacts/* ../backend-ai/artefacts/
```

### 2 – Configure environment

```bash
cp .env.example .env
# Edit .env as needed
```

### 3 – Start all services

```bash
docker compose up --build
```

Open **http://localhost:3000**

## Key Engineering Decisions

| Problem | Solution |
|---|---|
| Train/serve skew | `ecg_scaler.pkl` + `ehr_scaler.pkl` fitted once in training, loaded identically in FastAPI |
| SHAP latency (2-5s) | Background task queuing; UI shows "Calculating…" spinner with polling |
| ECG size mismatch | Pydantic `field_validator` enforcing exactly 1000 elements; 422 returned otherwise |
| LLM hallucination risk | Template-based scribe; gateway validates and never modifies Python's classifications |
| Security | Helmet, rate limiting, non-root containers, no PII stored or logged |
| Reliability | Docker healthchecks with `condition: service_healthy` dependency ordering |

## Clinical Standards

- **ACC/AHA 2022 Heart Failure Guidelines**
  - HFrEF: LVEF ≤ 40%
  - HFmrEF: LVEF 41–49%
  - HFpEF: LVEF ≥ 50%

- **NYHA Functional Classification**
  - Class I: No limitation
  - Class II: Slight limitation
  - Class III: Marked limitation
  - Class IV: Symptoms at rest
